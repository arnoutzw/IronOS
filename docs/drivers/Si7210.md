# Si7210 Hall Effect Sensor

The Si7210 driver provides support for Silicon Labs Si7210 Hall effect magnetic field sensor, used for detecting tip insertion/removal in soldering iron stands.

**Header File:** `source/Core/Drivers/Si7210.h`
**Implementation:** `source/Core/Drivers/Si7210.cpp`

---

## Overview

The Si7210 is a high-sensitivity Hall effect sensor used to:
- Detect when the iron is placed in a magnetic stand
- Trigger automatic sleep mode
- Wake the iron when removed from stand

---

## Conditional Compilation

The Si7210 driver is only available when `MAG_SLEEP_SUPPORT` is defined:

```c
#ifdef MAG_SLEEP_SUPPORT
class Si7210 {
    // ...
};
#endif
```

## Class: Si7210

The `Si7210` class provides static methods for Hall sensor operations.

---

## Functions

### detect

```c
static bool detect();
```

Probes the I2C bus to detect if a Si7210 sensor is present.

**Returns:**
- `true` - Si7210 found at expected I2C address
- `false` - Not detected

**Notes:**
- Called during hardware initialization
- Si7210 I2C address is typically 0x30-0x33

---

### init

```c
static bool init();
```

Initializes the Si7210 sensor for operation.

**Returns:**
- `true` - Initialization successful
- `false` - Initialization failed

**Configuration:**
- Sets high-range mode for stand detection
- Configures periodic measurement mode
- Sets appropriate sampling rate

---

### read

```c
static int16_t read();
```

Reads the current magnetic field strength.

**Returns:**
- Signed 16-bit magnetic field reading
- Positive values for one polarity, negative for opposite
- Magnitude indicates field strength

**Example:**
```c
int16_t field = Si7210::read();
if (abs(field) > threshold) {
    // Strong magnetic field detected - in stand
    enterSleepMode();
}
```

## Hall Effect Sleep Settings

The `HallEffectSensitivity` setting controls behavior:

| Value | Mode | Description |
|-------|------|-------------|
| 0 | Off | Hall sensor disabled |
| 1 | Low | High threshold (weak magnets) |
| 5 | Medium | Moderate threshold |
| 9 | High | Low threshold (sensitive) |

The `HallEffectSleepTime` setting controls the sleep delay after magnet detection.

---

## Integration with Sleep System

```c
void checkHallSensor() {
    if (!getHallSensorFitted()) return;

    int16_t reading = Si7210::read();
    uint16_t threshold = lookupHallEffectThreshold();

    if (abs(reading) > threshold) {
        // Magnet detected - iron in stand
        if (timeSinceDetection > getHallEffectSleepTimeout()) {
            enterSleepMode();
        }
    } else {
        // No magnet - iron out of stand
        if (isSleeping) {
            wakeUp();
        }
    }
}
```

## Magnetic Field Units

The Si7210 returns values in internal units that correspond approximately to:

| Reading | Field Strength |
|---------|----------------|
| 0 | No field |
| ±1000 | ~1 mT |
| ±10000 | ~10 mT |
| ±32767 | ~20 mT (max range) |

Typical stand magnets produce readings of 2000-10000 units.

## Example Usage

```c
void initHallSensor() {
    if (Si7210::detect()) {
        if (Si7210::init()) {
            hallSensorAvailable = true;
        }
    }
}

bool isInStand() {
    if (!hallSensorAvailable) return false;

    int16_t field = Si7210::read();
    uint16_t threshold = lookupHallEffectThreshold();

    return (abs(field) > threshold);
}
```
